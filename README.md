Title: Login and Registration System

Login and Registration System is a simple command-line application developed using C++. The program allows users to register a new account, log in using their username and password, and search for their account if they forget their password. User account information is stored in a text file using C++ file handling.

Features:
- User Registration
- User Login
- Username and Password Verification
- Duplicate Username Checking
- Forgot Password Option
- Account Search by Username
- File-based Data Storage
- Simple Menu-Driven Interface
- Exit Option

How to Run:
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Make sure a C++ compiler is installed.
4. Open the terminal in the project folder.
5. Compile the program using: g++ Login_Registration_System.cpp -o Login_Registration_System
6. Run the program: .\Login_Registration_System.exe
7. Follow the instructions displayed in the terminal.
